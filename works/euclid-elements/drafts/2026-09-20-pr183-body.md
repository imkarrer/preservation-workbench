Fixes #155.

## What

`parseParam` coerced any `Number()`-parsable token to a number. `Number("1 ")` is `1` (JS trims), so the digit-named points in `view/round_geometry/seventen.html` — `1 `, `2 `, … with a trailing space — were thrown away before the slate ever saw them, and nine elements failed on arity.

## The Java contract

The issue asked for a check against `geom_applet/source/`. `Slate.java` `selectDataChoice` (lines 344–393):

```java
try { // is it an integer?
  n[ncount] = Integer.parseInt(next);
  ncount++;
} catch (NumberFormatException exc) { // is it an element?
  Element elt = lookupElement (next);
```

**Number first, name on failure** — but `Integer.parseInt` does not trim whitespace, so `"1 "` threw and became a lookup. The trailing space is why the 1996 page worked. That's the contract this PR ports.

## Change

- `parseParam` — coerce only tokens with no surrounding whitespace (`s === s.trim()`). Padded tokens stay strings.
- `Slate.convertParams` — on a string that `lookupElement` misses, coerce to a number if it reads as one, else throw as before. Name lookup wins when both apply, so an element genuinely named `"1 "` is reachable. This also keeps programmatic callers who pass `"50"` working.
- `doc/api.md` — args-parsing paragraph updated.
- Tests: 2 in `ParseParamTest`, 2 in `SlateTest` (name-before-number resolution; numeric-string fallback; non-numeric miss still throws).

## Verification

- `npm run build` clean; `npm run test:unit` 473 passing (469 + 4).
- Snapshot suite run twice: goldens generated from unmodified `main`, then re-run with this change. **704 scenes bit-identical; exactly one differs** — `round/seventen/slate2`, which now constructs all 12 authored elements (was 3, 9 diagnostics → 0).
- Corpus survey: seventen's six names are the only whitespace-padded numeric tokens in any fixture under `view/`, and there are no float args, so the strict rule doesn't touch any other page.

Before the fix, `seventen` slate 2 rendered three orphan points (`1`, `2`, `4`); after, the full figure — three circles, three lines, six labelled points.
