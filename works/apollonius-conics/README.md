# Apollonius of Perga — *Conics*

Not started. Named by upstream as a desired sibling work.

Source text (verified 2026-09-20, see `docs/research/source-texts-licensing.md`):
T. L. Heath, *Apollonius of Perga: Treatise on Conic Sections* (Cambridge,
1896). Public domain in the US (pre-1931). Best scan: Internet Archive
`treatiseonconics00apolrich` (UC Libraries, non-Google, OCR + hOCR);
HathiTrust `uc2.ark:/13960/t4bp08b2n` (`pd`).

Caveats: Heath's text is a condensed paraphrase in modern notation that
combines propositions — the narrative rule binds to *Heath's* sentences, not
Apollonius'. OCR of the notation is poor; expect hand correction. Taliaferro
(1952), Toomer (1990) and Green Lion (1998–2013) are in copyright — do not use.
